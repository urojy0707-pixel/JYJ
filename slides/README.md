# GLP-1 작용제 — 작용 기전 및 분비조절 발표 자료

```bash
npm install pptxgenjs react-icons react react-dom sharp
node build_deck.js "GLP-1_작용기전_일반인설명.pptx"
```

바꾸면 전체 디자인이 함께 바뀝니다.
