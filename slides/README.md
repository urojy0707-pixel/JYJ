# GLP-1 작용제 작용 기전 — 일반인 대상 발표 자료

일반인(환자·보호자·교육 대상)에게 GLP-1 수용체 작용제의 작용 기전을
그림 중심으로 설명하는 한국어 발표 자료입니다.

## 산출물

- `GLP-1_작용기전_일반인설명.pptx` — 11장, 16:9

## 슬라이드 구성

| # | 내용 |
|---|------|
| 1 | 표지 |
| 2 | GLP-1은 원래 내 몸이 만드는 호르몬 (음식 → 창자 L세포 → 호르몬 → 뇌·췌장 흐름도) |
| 3 | 약은 "오래 버티도록 고친 복제품" (천연 1~2분 vs 세마글루타이드 약 7일) |

## 유지보수 시 주의

- 4번 슬라이드의 **허가 적응증·국내 공급 현황은 2026년 중반 기준**이며 수시로 바뀝니다.
  갱신 시 식품의약품안전처 허가정보를 확인하십시오.
- 7번 슬라이드의 체중 변화 수치는 **서로 다른 임상시험**에서 온 것으로 두 약의
  직접 비교가 아닙니다. 이 단서는 슬라이드 본문에 남겨 두십시오.
- 9번 슬라이드의 "불확실" 항목은 근거가 쌓이면 갱신이 필요합니다.

## 다시 빌드하기

```bash
npm install pptxgenjs react-icons react react-dom sharp
node build_deck.js "GLP-1_작용기전_일반인설명.pptx"
```

본문 글꼴은 맑은 고딕입니다. `build_deck.js` 상단의 색상 상수와 `K`(글꼴) 값을
바꾸면 전체 디자인이 함께 바뀝니다.
