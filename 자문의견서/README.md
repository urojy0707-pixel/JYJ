# 건강기능식품 자문 의견서

대웅제약 「흑곰샷」(건강기능식품 정제 + 일반식품 액상 듀얼팩)의 품목제조신고 적합성과
표시·광고 리스크에 관한 자문. 검토 근거자료는 「흑곰샷 제품 소개서」(26.08.11) 16면이다.

## 산출물

| 파일 | 형식 | 비고 |
|---|---|---|
| `흑곰샷_건강기능식품_신고적합성_자문의견서.pdf` | PDF | A4 19쪽, 나눔고딕 서브셋 임베드 |
| `흑곰샷_건강기능식품_신고적합성_자문의견서.hwpx` | HWPX | 한글 2010 이상에서 바로 열림 |

### 이전 산출물 (대체됨)

| 파일 | 비고 |
|---|---|
| `건강기능식품_원료_자문의견서_아르기닌아연비타민B.*` | 제품 확인 전 작성한 일반론 자문. 현행 판으로 대체되었다 |

> **HWP(.hwp) 관련 안내**
> `.hwp` 는 한컴의 비공개 바이너리 포맷이라 한컴오피스 없이 생성할 수 없다.
> 여기서는 한컴이 공개 표준(KS X 6101, OWPML)으로 제정한 **HWPX** 로 생성했다.
> 한글 2010 이상에서 `.hwpx` 는 이중클릭으로 그대로 열리며, 열어서 `.hwp` 로 저장하면 된다.

## 빌드

PDF 와 HWPX 는 같은 내용 소스를 쓰므로 항상 일치한다.

```bash
pip install python-hwpx
apt-get install -y fonts-nanum          # 한글 폰트(PDF 렌더링에 필요)

export CONTENT_MODULE=content2          # 기본값은 content(이전 판)

python3 make_hwpx.py 흑곰샷_자문의견서.hwpx   # HWPX 생성 + 스키마 검증
python3 make_html.py doc.html                 # 인쇄용 HTML 생성
chrome --headless --no-pdf-header-footer \
       --print-to-pdf=흑곰샷_자문의견서.pdf "file://$PWD/doc.html"
```

| 파일 | 역할 |
|---|---|
| `content2.py` | 현행 내용 소스 (흑곰샷) |
| `content.py` | 이전 내용 소스 (일반론, 대체됨) |
| `make_hwpx.py` | `python-hwpx` 로 HWPX 조판 (표 음영·열너비·머리말/꼬리말·문단서식) |
| `make_html.py` | 동일 소스를 인쇄용 HTML 로 조판 (A4 `@page`, 표 분할 방지) |

내용 블록 형식: `("h1"|"h2"|"h3"|"p"|"ul"|"ol"|"table"|"callout"|"mono"|"hr"|"pagebreak", ...)`.
본문 문자열의 `**굵게**` 는 두 조판기가 각각 런/`<strong>` 으로 변환한다.

## 검증 기록

- HWPX 스키마 검증: `Contents/header.xml`, `Contents/section0.xml` 통과, 이슈 0건
- HWPX 패키지 검증: 통과 (경고 1건 — manifest 의 version part 미참조, `version.xml` 폴백으로 동작)
- PDF: A4 19쪽, 임베드 폰트 NanumGothic / NanumGothicBold (대체 폰트 없음)
- 두 산출물의 텍스트 역추출 대조로 내용 일치 확인

## 문서 성격 및 한계

- 검토 근거는 **제품 소개서 16면에 기재된 정보뿐**이다.
  실제 배합비·원료 규격서·시험성적서·최종 라벨 시안은 확인하지 못했다.
- 문헌 검색이 아닌 **지식 기반 작성**이다. 인용 문헌의 서지사항은 원문 대조가 필요하다.
- 3장(엽산·아연 함량 범위 초과)의 판단은 **고시 원문을 대조하지 못한 상태의 추정**이다.
  확인이 필요한 항목은 본문 10장에 명시해 두었다.
- 규제 판단은 **유권해석이 아니다.** 식약처 최신 고시 및 사전 상담으로 확정할 것.
- 주장별 근거 강도는 본문에서 A(확립) / B(중등도) / C(제한적) / D(불충분) / N(음성근거) 로
  구분해 표기했다. 이 구분을 떼어내고 인용하면 부당광고 위험이 있다.
