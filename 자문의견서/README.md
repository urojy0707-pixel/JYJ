# 건강기능식품 원료 자문 의견서

L-아르기닌 · 아연 · 고함량 비타민 B군 배합에 관한 자문. 제2판에서 대웅제약 「흑곰샷」
제품 소개서(26.08.11)를 검토 대상으로 삼아 품목제조신고 적합성 자문으로 전환했다.

## 산출물

### 제2판 — 흑곰샷 특정 (현행)

| 파일 | 형식 | 비고 |
|---|---|---|
| `흑곰샷_건강기능식품_신고적합성_자문의견서_제2판.hwpx` | HWPX | A4 20쪽 상당 |
| `흑곰샷_건강기능식품_신고적합성_자문의견서_제2판.pdf` | PDF | A4 20쪽, 나눔고딕 서브셋 임베드 |

### 제1판 — 일반론 (폐기, 이력 보존용)

| 파일 | 형식 | 비고 |
|---|---|---|
| `건강기능식품_원료_자문의견서_아르기닌아연비타민B.hwpx` | HWPX | **오류 2건 포함 — 사용하지 말 것** |
| `건강기능식품_원료_자문의견서_아르기닌아연비타민B.pdf` | PDF | A4 16쪽 |

> **제1판을 폐기한 이유**
> 1. 「건강기능식품에서 비타민 B군은 영양성분 기준치의 30~150%로 제한된다」는 서술이 **틀렸다.**
>    하한이 30%인 것은 맞으나 상한은 원료별로 개별 설정되며 훨씬 높다(B1 100 mg, 나이아신 670 mgNE 등).
>    이 오류 위에 세운 「제도 트랙 결정(건기식/일반의약품/일반식품)」 장 전체가 무의미했다.
> 2. L-아르기닌 안전성 경고(VINTAGE MI, 9 g/일)를 1,000 mg 설계에 과잉 적용했다.
>
> 정정 내용은 제2판 0장에 기록되어 있다.

> **HWP(.hwp) 관련 안내**
> `.hwp` 는 한컴의 비공개 바이너리 포맷이라 한컴오피스 없이 생성할 수 없다.
> 여기서는 한컴이 공개 표준(KS X 6101, OWPML)으로 제정한 **HWPX** 로 생성했다.
> 한글 2010 이상에서 `.hwpx` 는 이중클릭으로 그대로 열리며, 열어서 `.hwp` 로 저장하면 된다.

## 빌드

두 산출물은 `content.py` 하나를 공통 소스로 쓰므로 내용이 항상 일치한다.

```bash
pip install python-hwpx
apt-get install -y fonts-nanum          # 한글 폰트(PDF 렌더링에 필요)

# CONTENT_MODULE 로 판 차수를 고른다 (기본값 content = 제1판)
export CONTENT_MODULE=content2

python3 make_hwpx.py 흑곰샷_자문의견서_제2판.hwpx   # HWPX 생성 + 스키마 검증
python3 make_html.py doc2.html                      # 인쇄용 HTML 생성
chrome --headless --no-pdf-header-footer \
       --print-to-pdf=흑곰샷_자문의견서_제2판.pdf "file://$PWD/doc2.html"
```

| 파일 | 역할 |
|---|---|
| `content2.py` | **제2판** 내용 소스 (흑곰샷 특정) |
| `content.py` | 제1판 내용 소스 (폐기, 이력 보존용) |
| `make_hwpx.py` | `python-hwpx` 로 HWPX 조판 (표 음영·열너비·머리말/꼬리말·문단서식) |
| `make_html.py` | 동일 소스를 인쇄용 HTML 로 조판 (A4 `@page`, 표 분할 방지) |

## 검증 기록

제2판 기준:

- HWPX 스키마 검증: `Contents/header.xml`, `Contents/section0.xml` 통과, 이슈 0건
- HWPX 패키지 검증: 통과 (경고 1건 — manifest 의 version part 미참조, `version.xml` 폴백으로 동작)
- PDF: A4 20쪽, 임베드 폰트 NanumGothic / NanumGothicBold (대체 폰트 없음)
- 두 산출물의 텍스트 역추출 대조로 내용 일치 확인

## 문서 성격 및 한계

- 검토 근거는 **제품 소개서 16면에 기재된 정보뿐**이다. 실제 배합비·원료 규격서·시험성적서·최종 라벨 시안은 확인하지 못했다.
- 문헌 검색이 아닌 **지식 기반 작성**이다. 인용 문헌의 서지사항과 최신 메타분석 반영 여부는 원문 대조가 필요하다.
- 제2판 3장(엽산·아연 함량 범위 초과)의 판단은 **고시 원문을 대조하지 못한 상태의 추정**이다.
  제2판 10장에 확인이 필요한 항목을 명시해 두었다.
- 본문의 영양성분 기준치·일일섭취량 범위·기능성 표시 문구는 **법적 유권해석이 아니다.**
  식약처 「건강기능식품의 기준 및 규격」 고시 최신본 및 식품안전나라 원료 데이터베이스에서 반드시 대조할 것.
- 주장별 근거 강도는 본문에서 A(확립) / B(중등도) / C(제한적) / D(불충분) / N(음성근거) 로 구분해 표기했다.
  이 구분을 떼어내고 인용하면 부당광고 위험이 있다.
